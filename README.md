# Deviprasad Project

## 🧾 Project Info

This project is built using modern front-end technologies:

- **Vite** – Fast dev server and build tool
- **React** – UI library
- **TypeScript** – Static type checking
- **Tailwind CSS** – Utility-first CSS framework
- **shadcn/ui** – Reusable component library
